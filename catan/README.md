# Catan - A Web-Based Board Game

This project is a web-based implementation of the popular board game Catan, built with Python and Flask.

## How to Play

### 1. Installation

First, you need to install the necessary Python dependencies. The only external dependency for this project is Flask. You can install it using pip:

```bash
pip install Flask
```

### 2. Running the Game

Once the dependencies are installed, you can start the game by running the Flask web server. The main application file is located at `web/app.py`.

To run the server, navigate to the `catan` directory in your terminal and execute the following command:

```bash
python3 web/app.py
```

### 3. Accessing the Game

After running the command above, the web server will start. You can access the game by opening your web browser and navigating to the following address:

[http://127.0.0.1:5001](http://127.0.0.1:5001)

You can also access it from other devices on the same network at `http://<your_local_ip>:5001`.

The game board and all interactive elements will be displayed in your browser. You can now play Catan!
